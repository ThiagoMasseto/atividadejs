# Explore a Natureza (Atividade JS)

[🇧🇷 Português](#-português) | [🇺🇸 English](#-english)

---

## 🇧🇷 Português

Projeto interativo em HTML, CSS e JavaScript que sincroniza a rolagem de imagens com seções de texto utilizando a API **`IntersectionObserver`**.

### ✨ Funcionalidades
- Galeria com rolagem vertical de paisagens (natureza, praias, montanhas e florestas)
- Detecção automática da imagem visível (`threshold: 0.6`) para destacar a imagem e exibir o texto correspondente
- Navegação suave (`scrollIntoView`) ao clicar nas imagens

### 🛠️ Tecnologias
- HTML5
- CSS3 (`css/style.css`)
- JavaScript Vanilla (`js/script.js`)

### 🚀 Como executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/ThiagoMasseto/atividadejs.git
   ```
2. Abra o arquivo `index.html` no navegador.

## 🇺🇸 English

Interactive HTML, CSS, and JavaScript project that synchronizes image scrolling with matching text sections using the **`IntersectionObserver`** API.

### ✨ Features
- Vertical scrollable landscape gallery (nature, beaches, mountains, and forests)
- Automatic detection of the active image (`threshold: 0.6`) to highlight it and switch the displayed text section
- Smooth scrolling (`scrollIntoView`) when clicking an image

### 🛠️ Technologies
- HTML5
- CSS3 (`css/style.css`)
- Vanilla JavaScript (`js/script.js`)

### 🚀 How to run
1. Clone the repository:
   ```bash
   git clone https://github.com/ThiagoMasseto/atividadejs.git
   ```
2. Open `index.html` in your browser.
